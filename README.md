# Совместная библиотека

Учебный проект на Go: пользователи читают книги и по очереди дописывают их
неизменяемыми фрагментами с сохранением авторства.

Главная цель — самостоятельно понять и реализовать небольшой бэкенд.
Перед каждой фичей обсуждаем назначение, сценарий, способ реализации и проверки.
План можно упрощать по совместному решению.

Формат работы: **объяснение → самостоятельная попытка → проверка и подсказки**.
Новые инструменты осваиваем постепенно; готовую реализацию от помощника
запрашиваем отдельно.

## Основа проекта

Одно Go-приложение, REST API с JSON и PostgreSQL. Выбранные инструменты:
`net/http`, `pgx/v5`, `goose`, `log/slog`, Docker Compose; позднее — Prometheus
и Grafana. Полный стек подключаем по мере появления учебных задач.

## Основные договорённости

- Читать все нескрытые книги могут все вошедшие пользователи.
- Создатель может ограничить круг тех, кто продолжает книгу.
- Книгу пишет один пользователь за раз; срок занятия — 20 минут.
- «Сохранить и выйти» публикует фрагмент; «Выйти без сохранения» отменяет заход.
- Черновиков, периодического сохранения текста и фоновой публикации нет.
- Предупреждение на 17-й минуте и попытку отправки на 20-й выполняет будущий
  интерфейс. При закрытии страницы сохранение текста не гарантируется.
- Бюджет — нулевой; конкретное размещение обсуждаем ближе к готовности проекта.

# Совместная библиотека

Сервис для совместного написания книг на Go. Пользователи смогут создавать
книги и по очереди дописывать их. У каждого фрагмента сохраняется автор,
опубликованный текст нельзя редактировать.

## Состояние проекта

Сейчас работают HTTP-сервер, маршрут `GET /health`, настройка адреса через
переменную окружения и логирование запуска через `log/slog`.

Далее — PostgreSQL, регистрация и вход, каталог книг, публикация фрагментов,
профили авторов и лайки.

Основные правила будущего сервиса:

- Читать книги могут все вошедшие пользователи. Создатель книги может
  ограничить круг тех, кому разрешено её продолжать.
- Одну книгу пишет один пользователь за раз. Время одного захода — 20 минут.
- «Сохранить и выйти» публикует фрагмент, «Выйти без сохранения» отменяет заход.
- Черновиков нет. Будущий интерфейс предупреждает за 3 минуты до окончания
  и по таймеру пытается отправить текст. При закрытии страницы или потере
  соединения сохранение не гарантируется.

## Запуск

Нужен Go 1.26.1 или новее. Команды выполняются из корня проекта.

```sh
go run ./cmd/api
```

По умолчанию сервер слушает `127.0.0.1:8080`. Чтобы изменить адрес:

```sh
HTTP_ADDR=127.0.0.1:9090 go run ./cmd/api
```

Проверка сервера при запуске с адресом по умолчанию:

```sh
curl -i http://127.0.0.1:8080/health
```

Ответ: `200 OK`, `Content-Type: application/json` и тело:

```json
{"status":"ok"}
```

Маршрут проверяет доступность HTTP-сервера. Проверки подключения к БД пока нет.
